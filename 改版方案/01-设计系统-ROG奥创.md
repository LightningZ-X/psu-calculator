# 设计系统：ROG 奥创（Armoury Crate）风格规范

> 来源：华硕官方 [Armoury Crate 页面](https://rog.asus.com.cn/content/armoury-crate/) 的真实 UI 截图（ROG 主题首页 / Scenario Profile 页），以及页面自身 `assets/og-image.png`。
> 本文是**改版的唯一视觉依据**。所有提示词都引用本文，不再重复描述。

---

## 1. 从截图里提取的 10 条硬事实

| # | 观察到的特征 | 截图证据 | 落地结论 |
| --- | --- | --- | --- |
| 1 | 主内容区底色是**接近纯黑的中性色**，不是蓝灰 | 右侧整片背景 | 底色 `#121212`，**不要用蓝调深色** |
| 2 | 左侧导航栏**比主内容区更黑**，用亮度差分区 | 侧边栏明显比内容区暗 | 分区靠「亮度层级」而非「边框」 |
| 3 | 强调色是 **ROG 红**，只出现在极小面积上 | 分区标题前的双斜杠、选中项下划条、滑块 | 红色面积占比 **< 3%**，且**不用渐变大色块** |
| 4 | 分区标题前有一个**双斜杠小图形**（`>>` 变形） | "Systems Monitor"、"Operating Mode" 前 | 这是 ROG 最强的视觉签名，必须复刻 |
| 5 | 分区标题下有**极细的深色下划线** | 标题下一整条暗线 | 用 1px 低对比线做分区，而非卡片描边 |
| 6 | 数据区是「**标签 + 细点线 + 右对齐数值**」三件套，不是卡片 | Frequency / Temperature / Usage / Fan 四栏 | 密集数据用**行式列表**，不要一数据一卡片 |
| 7 | 数值用**等宽感的无衬线、白色**；次要项灰色或画 `--` 占位 | 2700 MHz、42 ℃、`--` | 数值等宽 + `tabular-nums`；**空值用 `--` 而不是 "0"** |
| 8 | 输入控件是**深色填充 + 上下描边**，几乎看不到完整边框 | Scenario 页的 Win Key / Volume 行 | 表单行做成 **row 形态**，不是 label 上、input 下 |
| 9 | 开关是**右对齐的小胶囊 ON/OFF** | 同上 | 设置行统一「左标签 —— 右控件」 |
| 10 | 模式选择是**大图标 + 文字 + 选中项红色下划条** | Quiet / Standard / Turbo / Full Speed / Custom | 这个组件可以**直接复用到「使用场景」选择** |

## 2. 设计 token

### 2.1 颜色

```css
:root{
  /* 背景：三级亮度，靠亮度差而不是描边来分区 */
  --bg:          #121212;   /* 主内容区 */
  --bg-soft:     #181818;   /* 次级凹陷区（输入框、代码块） */
  --bg-nav:      #0a0a0a;   /* 侧栏 / 顶栏，最暗 */
  --surface:     #1a1a1a;   /* 浮起表面（下拉菜单、抽屉、气泡） */
  --surface-2:   #202020;   /* 表面上的悬停态 */

  /* 描边：极低对比，只在需要时出现 */
  --line:        #2a2a2a;
  --line-soft:   #202020;

  /* 文本：四级，比页面上常用少一档 */
  --text:        #ffffff;   /* 标题与关键数值 */
  --text-2:      #c8c8c8;   /* 正文 */
  --text-3:      #8a8a8a;   /* 标签、说明 */
  --text-4:      #5a5a5a;   /* 占位符、禁用、`--` */

  /* ROG 红：全局唯一强调色，克制使用 */
  --rog:         #ff0033;
  --rog-dim:     #c40028;
  --rog-glow:    rgba(255,0,51,.35);

  /* 状态色：只用于「有语义」的地方，不做装饰 */
  --ok:          #16a34a;
  --warn:        #e08600;
  --err:         #ff0033;   /* 与 ROG 红同色：危险 = 品牌色，合理 */

  /* 数据可视化专用（仅图表/进度条，不进 UI 装饰） */
  --data-1:      #ff0033;
  --data-2:      #4a9eff;
  --data-3:      #16a34a;

  --radius:      2px;       /* 关键：奥创几乎不用大圆角 */
  --radius-lg:   4px;
  --mono: ui-monospace, "Cascadia Mono", Consolas, "SF Mono", monospace;
  --sans: "Segoe UI", "Microsoft YaHei", "PingFang SC", system-ui, sans-serif;
}
```

**关键认知：当前站点用 `--radius: 10px` + 五颜六色（青/蓝/橙/紫）+ 渐变 logo，这三点是「AI 模板感」的主要来源。奥创风格是把圆角收到 2px、颜色砍到只剩红 + 数据色、去掉渐变。**

### 2.2 排版

| 用途 | 字号 / 字重 / 字距 | 备注 |
| --- | --- | --- |
| 关键数值（推荐瓦数） | 56px / 700 / -0.02em | 等宽 + `tabular-nums`，全页唯一的大字 |
| 分区标题 | 20px / 700 / 0 | 前面带双斜杠图形 |
| 卡片标题 | 15px / 600 / 0.01em | |
| 正文 | 14px / 400 / 0 | 行高 1.65 |
| 标签 | 12px / 500 / 0.02em | 颜色 `--text-3` |
| 数据行数值 | 13px / 600 / 0 | 等宽 |
| 小字注释 | 12px / 400 | 优先塞进 tooltip，不要铺在页面上 |

**字体策略**：奥创用一套「方正、略带工业感的无衬线」。中英文混排下不要引入外链字体（会拖慢首屏且中文子集巨大）。用 `system-ui` 栈 + 字重对比来做出气质，英文数字用等宽字体做「仪表感」。如果一定要更接近，推荐本地可选字体：`"Segoe UI Variable Display", "HarmonyOS Sans SC", "MiSans"`。

### 2.3 圆角、描边、阴影、间距

- **圆角**：`2px`（默认）/ `4px`（浮起表面）。**不要 `10px`、不要胶囊按钮**（唯一例外：开关和 tag）。
- **描边**：`1px solid var(--line)`。分区优先用**上下 1px 细线**，不要给每块都套完整矩形。
- **阴影**：只给真正浮起的层（下拉、抽屉、tooltip）：`0 8px 32px rgba(0,0,0,.6)`。**平面卡片不允许有阴影。**
- **间距**：4px 基准。卡片内 20px，卡片间 12px，分区间 32px，页面左右 32px。
- **发光**：只有当前选中项或关键数值允许 `text-shadow: 0 0 20px var(--rog-glow)`，且**最多一处**。

## 3. 必须复刻的 6 个标志性组件

### 3.1 双斜杠分区标记（品牌签名）

```css
.slash::before{
  content:"";
  display:inline-block; width:14px; height:14px; margin-right:10px;
  vertical-align:-1px;
  background:
    linear-gradient(115deg, transparent 38%, var(--rog) 38%, var(--rog) 52%, transparent 52%),
    linear-gradient(115deg, transparent 58%, var(--rog) 58%, var(--rog) 72%, transparent 72%);
}
```
两片平行四边形向右倾斜，就是 ROG 的 `>>` 标志。**每个分区标题都必须有它**——这是让页面「一眼 ROG」的第一要素。

### 3.2 数据行（替代「一个数据一张卡」）

```
CPU 主频 ······················· 2700 MHz
CPU 封装温度 ···················    42 ℃
内存 0 ·························    -- 
```
```css
.datarow{ display:flex; align-items:baseline; gap:10px; padding:7px 0; }
.datarow .fill{ flex:1; border-bottom:1px dotted var(--line); transform:translateY(-3px); }
.datarow .val{ font-family:var(--mono); font-variant-numeric:tabular-nums; }
.datarow .val.empty{ color:var(--text-4); }
```

### 3.3 设置行（表单的奥创形态）

替代当前「label 在上、input 在下」的堆叠式表单：
```
┌──────────────────────────────────────────────┐
│  超频模式                          [  ON  ]  │
│  解锁功耗墙 / 自定义功耗                      │
└──────────────────────────────────────────────┘
```
- 整行 56px 高，`border-top: 1px solid var(--line-soft)`，**无左右边框**
- 左：标签（14px 白）+ 副说明（12px 灰）
- 右：控件（开关 / 下拉 / 数值），宽 200px 右对齐
- 下拉用奥创的**方角深色框**，不是浏览器默认样式

### 3.4 模式选择器（复用于「使用场景」）

```
   ⌂        ◈        ⚡        ⚙        ✦
 办公      游戏     创作     静音     自定义
 ━━━━━   ━━━━━   ━━━━━   ━━━━━   ━━━━━
          (选中项红色下划条)
```
- 一格 96px 宽，图标 22px，文字 12px
- 未选中：`--text-3`，无边框；选中：白色文字 + 底部 `3px var(--rog)` 条
- **不要**用 `.scenario.on` 现在的「青色描边 + 青色底」写法

### 3.5 分段条 `>>` 进度指示（用于分区标题右侧）

复用 3.1 的双斜杠图形，横向重复 3~4 次，透明度递减，做「仪表刻度」感。

### 3.6 关键数值块

```
推荐电源功率
    850 W                    ← 56px 等宽白字
买 850W 的 ATX 3.1 电源       ← 14px 灰字一句话结论
```
- 上方标签 12px 灰，全部大写或加字距
- 数字与单位之间留 6px，单位 20px 灰
- 允许一条 `4px` 红色短下划条在数字左下方（对应截图里的红色指示条）

## 4. 三条「反 AI 感」铁律

改造过程中必须持续自查。**违反任意一条，页面就会重新变成「一眼 AI」。**

| 铁律 | 错误做法（当前站点 / 常见 AI 输出） | 正确做法 |
| --- | --- | --- |
| **① 一种强调色，且极小面积** | 青 + 蓝 + 橙 + 紫四种强调色，按钮/徽标/标签各用一种 | 只有 ROG 红一种，总面积 < 3%，其余全是灰阶 |
| **② 不要渐变、不要发光、不要 emoji 当图标** | `linear-gradient(135deg, 青, 蓝)` 的 logo、`⚡⚠️☀★✨` 当图标、卡片描边五颜六色 | 纯色块 + 内联 SVG 图标（描边风格，`stroke-width:1.5`，`currentColor`） |
| **③ 形态多样化：分组靠亮度，不靠卡片** | 每块内容都套同一个「深色面板 + 1px 描边 + 10px 圆角」 | 数据用行式列表、设置用带分隔线的行、分区用上下细线，只有需要凹陷/浮起时才用容器 |

**补充自查项**：
- 圆角是否 ≤4px？（大圆角是 Web 模板味，不是游戏 UI 味）
- 页面上是否还有 emoji？全部清掉，换 SVG。
- 是否所有卡片长得一模一样？那样等于没有信息层级。
- 数字是否等宽、右对齐、`tabular-nums`？
- 空值是否用 `--` 而不是 `0`？
- 悬停/选中是否**只有**两种状态变化（描边变亮 + 红色指示条），而不是同时变色 + 位移 + 发光 + 缩放？

## 6. 可达性与工程约束（不可牺牲）

1. **对比度**：正文 ≥ 4.5:1，大字 ≥ 3:1。`--text-3: #8a8a8a` 在 `#121212` 上约 5.6:1，达标；`--text-4` 仅用于非信息性占位。
2. **焦点可见**：`:focus-visible { outline: 2px solid var(--rog); outline-offset: 2px; }`，禁止 `outline:none`。
3. **`prefers-reduced-motion: reduce`**：关闭全部过渡与动画。
4. **深浅主题**：必须保留 `html[data-theme="light"]`（`#btnTheme` 依赖它）。浅色版：底 `#f5f5f5`、面 `#ffffff`、线 `#e0e0e0`、文本 `#111`，ROG 红压深为 `#d40029` 保证达标。
5. **打印**：`@media print` 必须把红色指示条、发光、渐变全部压平为纯色/无色，保留结构线。导出的 PDF 是这工具的重要出口。
6. **无外部依赖**：不引入字体 CDN、不引入 CSS 框架、不引入图标库（图标以内联 SVG 或 CSS 图形实现）。
7. **无构建步骤**：产物必须能直接上传 GitHub Pages。
