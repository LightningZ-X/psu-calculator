# 2026-09-14

## 鹈鹕骑自行车 SVG 动画

- 文件：`pelican-bike.html`（纯 SVG + CSS，无外部依赖，单文件）
- 场景：深蓝夜空 + 星星 + 月亮光晕 + 远山剪影 + 滚动路面虚线
- 动画层：车轮旋转(0.7s)、曲柄(1.4s)、双腿交替蹬踏(反相位)、头颈/翅膀摆动、身体颠簸、速度线、云朵漂移、眨眼(4.6s)、围巾飘动
- 支持 `prefers-reduced-motion`

### 关键经验（造型）
- 第一版鹈鹕画得像「白色鸭子」：头骨 r=30 过大、喙只有头宽的 1.5 倍且带尖钩近似鸭嘴，喉囊几乎看不出。
- 修正方案（鹈鹕辨识度三要素）：
  1. 头骨缩小到 r=24，眼睛位置后移，前方留白给喙
  2. 喙改为**又长又直**：从 x=144 延伸到 x=282（约头宽的 3 倍），喙尖保留小下钩
  3. 喉囊做大做松垂：占宽 116px、下垂 ~56px，加内侧褶皱纹路多条
- 颈改为细长 S 形，`transform-origin: 6% 92%` 让摆动支点落在身体接缝处

### 重做：定位问题（第二版 → 第三版）
用户反馈「位置不对」。根因有两个：

**1. viewBox 比例与屏幕比例不匹配**
- 旧：`viewBox="0 0 1000 640"` + `preserveAspectRatio="xMidYMid slice"`
- 宽高比 1.5625，而常见屏幕是 1.78+ → `slice` 为铺满而裁掉上下、撑开左右，主体被切到屏幕外
- 修复：`viewBox="0 0 1000 620"` + `meet`（等比完整显示，不裁切）

**2. 元素坐标是随手写的散点，没有统一基准**
- 修复：建立一套「bench 局部坐标系」，全部以**地面线 y=0** 为基准：
  - 车轮半径 66 → 轮心 y=-66
  - 五通(踩踏中心) (0,-64) · 座垫顶 y=-216 · 髋 (-26,-218) · 肩 (26,-286) · 头心 (118,-336) · 喙尖 x=268
  - 车身宽约 250、高约 380 单位
- 定位：`translate(433,518)`，使车轮接地点精确落在路面虚线 y=518 上

### 重要教训
**SVG 场景务必用脚本做数值校验**，不要靠肉眼估坐标。可计算验证项：
- 触地：轮心 y + 半径 == 路面 y
- 居中：主体包围盒中心 vs viewBox 中心
- 越界：所有关键点是否落在 viewBox 内
本次校验就抓出了「车轮悬空 42px」「主体偏左 80px」两处凭肉眼极易漏掉的错误。
