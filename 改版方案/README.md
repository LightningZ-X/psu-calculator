## 30 秒读懂结论

### 起点校准（重要）

分析时发现：**你的本地 `psu-calculator/` 已经比线上新一版，而且已经做过一轮奥创风格改版。**

| 项 | 线上 | 本地 |
| --- | --- | --- |
| `assets/style.css` | 401 行 / 17.7 KB | **725 行 / 32.2 KB**（token 已换成奥创青 `#00d4ff`、`--radius: 14px`） |
| `js/ui.js` | 无 | **已新增**（卡片折叠 + 当前卡高亮 + 移动端结果条） |
| `js/app.js` / `engine.js` / `db*.js` | — | **与线上同字节（计算层没动，好事）** |
| `tools/` | 无 | 已有 4 个脚本（含 `selftest.mjs`、`browsertest.mjs`） |

**已完成的（不要再做）**：免责 banner 折叠、引导瘦身、卡片折叠、当前卡高亮、卡内长说明收纳、移动端结果条、`:focus-visible`、`prefers-reduced-motion`、`--text-mute` 提亮。

### 但那一轮是「换皮没收敛」，而且真正的问题没修

**上一轮改版把字号从 15 档涨到了 18 档（9.5~40px）、`var(--accent)` 用了 34 次、加了 ⚡ 呼吸发光动画、圆角从 10px 加到 14px。** 这是「越改越花」。

而会审发现真正的问题是三个**功能性缺陷**，它们**在本地版本里依然存在**（已核对行号）：

1. 🔴 **什么都没选的时候，页面会打绿勾说「全部匹配」**（`app.js:697`），还推荐 3 款电源。直接摧毁工具可信度。
2. 🔴 **首次访问会自动灌入 RTX 5090 旗舰配置**（`app.js:1093`），新用户第一眼看到的是别人机器的 1200W，而 header 里还摆着「载入示例配置」按钮，自相矛盾。
3. 🔴 **手机上根本看不到推荐瓦数**——`sticky` 定位实际失效，窄屏时结果列被排到 10 张配置卡之后，要滚约 10 屏。`ui.js` 的移动端条只显示了数字，**没解决这个根因**。

**另外**：`canonical` / `og:url` / `og:image` / `twitter:image` **四处仍是 `example.com`**（你自己在 `index.html:8-10` 注释里标注了，没替换）→ 分享到微信/飞书抓不到图。可达性仍是零（`label for=` **0 个**、`aria-*` **0 个**、屏幕上看不到 `<h1>`）。
